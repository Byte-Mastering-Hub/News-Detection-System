> **"Detecting Misinformation with 98.79% Accuracy"**

TruthScope AI is a machine learning-powered web application that detects fake news and manipulative content with high accuracy. Built with Python Flask backend and modern HTML/CSS/JS frontend, it provides real-time predictions with confidence scores and explainable results through suspicious phrase highlighting.

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🔍 **Real-time Analysis** | Instant fake news detection with <0.8s response time |
| 📊 **Confidence Meter** | Visual confidence score with High/Medium/Low badges |
| 🎨 **Suspicious Phrase Highlighting** | Color-coded detection of emotional, clickbait, manipulative, and exaggerated language |
| 🌓 **Dark/Light Theme** | User preference saved across sessions |
| 📈 **Detailed Statistics** | Category, risk level, sentiment, and manipulation percentage |
| 💾 **Offline Operation** | Complete privacy - no data leaves your computer |
| 🔄 **Feedback System** | Users can provide feedback on predictions |
| 📱 **Responsive Design** | Works on desktop, tablet, and mobile devices |
